## 3. note 互換記法への変換

| 箇所 | 変換前 | 変換後 | 理由 |
| --- | --- | --- | --- |
| セクション X | Markdown 表 | 箇条書き / 画像化指示 | note は表に非対応 |
| セクション Y | Mermaid | GPT イラスト / 作図指示 | note は Mermaid に非対応 |
| コードブロック | ```` ```ts:src/foo.ts ```` | ファイル名を地の文へ | note にファイル名・言語指定記法なし |
| インラインコード | `` `code` `` | 太字 / 「」 | note はインラインコードに非対応 |
| `:::message` | | 太字段落 + 引用ブロック | Zenn 独自記法 |
| `:::details` | | 展開して本文へ | Zenn 独自記法 |
| 脚注 | `[^1]` | インラインリンク / 括弧書き | note は脚注に非対応 |
| H4 以下 | | 太字段落 | note の見出しは 2 レベル |

## 6. Phase 5 完了チェックリスト

**Phase 5 は「公開可能な下書き + 画像プロンプトを作る」までで完了する。** `status: draft` のまま完了してよい。公開そのものは Phase 5 の完了後に人間が行う（セクション 7 を参照）。

### 変換の妥当性

- [ ] title が数値または結論を含む（3 案からユーザーが選択）
- [ ] hashtags が 3-8 件で、note の既存タグに合わせている
- [ ] 見出しが H2 / H3 のみ
- [ ] 冒頭 2 文で記事の価値を言い切っている
- [ ] 「この記事でわかること」「結論」「まとめ」「参考リンク」セクションがある
- [ ] `status` が `draft`、`paid` が `false` である
- [ ] 事実・数値・留保がレビュー済み原稿と一致している（変換で意味を変えていない）

### 画像

- [ ] 見出し画像のプロンプト・Alt text・キャプションがある
- [ ] 差し込み画像のプロンプトに共通ベーススタイルが付いている
- [ ] 数値を含む表・グラフを GPT 生成の対象にしていない

## 7. 公開手順（Phase 5 完了後、人間が実施）

**このセクションは Phase 5 の完了条件に含まれない。** エージェントは以下を実行しない。

### 公開ゲート（人間）

- [ ] GPT で画像を生成し、`note/images/YYYY-MM/` に保存して内容を確認した
- [ ] **人間が記事全文を読み、自分の言葉として責任を持てるよう加筆修正した**
- [ ] note の規約・生成 AI 関連のヘルプを**公式ページで再確認**した（`.claude/rules/platforms/note.md` の「最重要の制約」参照）。確認できない場合は公開しない
- [ ] AI 学習提供の設定（アカウント / 記事単位）を確認・判断した

### 公開作業

1. frontmatter を除去し、本文を note エディタに貼り付ける（手順は `.claude/rules/platforms/note.md` の「公開モデル」）
2. 貼り付け結果を目視確認する（見出しレベル・引用・コードブロック・強調）。リンクを付け直し、画像を再アップロードする
3. タイトルをタイトル欄に入力し、見出し画像（アイキャッチ）を設定する
4. ハッシュタグを設定する
5. 有料設定（無料 / 有料）を判断する
6. 公開する
